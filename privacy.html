Privacy policy

Effective date: 28 October 2026

This policy describes how gdrive-cli (“the app”), a command-line tool that runs on the user's own computer, handles Google user data.

Data the app accesses

The app requests only the Google OAuth scope https://www.googleapis.com/auth/drive.file. With it, the app can see, create, and manage only the files and folders that the app itself created in the user's Google Drive, and can read the user's email address and storage quota shown by the Drive API. It cannot access any other file in Google Drive, nor Gmail, Contacts, or other Google services.

How the data is used

Data is used only to perform the actions the user runs on their own computer: uploading files and folders, setting them to “anyone with the link can view”, listing them, printing their links, and downloading them. Files uploaded with the app are intentionally made shareable by link; the user is told this before use.

Storage and sharing

The app has no server. The OAuth refresh token and settings are stored only on the user's computer (for example %APPDATA%\gdrive on Windows). The developer does not collect, store, sell, or transfer any user data, and no data is sent to anyone other than Google's APIs.

Limited Use

gdrive-cli's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Users can revoke the app's access at any time at myaccount.google.com/permissions, and delete the local token by running gdrive logout.

Contact

Questions about this policy: GitHub issues.

Tóm tắt tiếng Việt

Ứng dụng chỉ xin quyền drive.file: chỉ thấy và quản lý file/thư mục do chính nó tạo trong Google Drive của người dùng. Dữ liệu chỉ dùng để thực hiện lệnh người dùng chạy trên máy mình (đẩy, công khai bằng link, liệt kê, tải về). Không có máy chủ; token đăng nhập chỉ nằm trên máy người dùng; nhà phát triển không thu thập, lưu, bán hay chuyển dữ liệu cho ai. Thu hồi quyền tại myaccount.google.com/permissions.
